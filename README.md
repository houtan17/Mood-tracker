# Mood-tracker
A lightweight, offline-first web app that lets you track your daily mood using the Persian calendar. Data is saved locally in the browser so your previous entries reappear the next time you open the app.
Features

Persian (Jalali) calendar view
Quick mood selection with emojis & color indicators (Excellent → Very Bad)
Local storage persistence (no account needed)
Clean, modern, light-colored UI
Fully responsive (works well on mobile)
Bilingual support (Persian + English toggle)
Backup / Restore functionality
Simple and easy-to-edit file structure (HTML, CSS, JavaScript)

Tech Stack

HTML5
CSS3 (modern, responsive design)
Vanilla JavaScript
LocalStorage for data persistence

How to use

Open the app
Select a date on the Shamsi calendar
Choose your mood
Your data is automatically saved and will be available next time
